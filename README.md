# Личный ИИ-Радар — passive-first Android prototype

`Личный ИИ-Радар` — это не обычный блокнот, не todo-лист и не приложение, в котором человек должен постоянно сидеть и вручную писать напоминания.

Главная цель приложения: **пассивно работать на телефоне владельца, смотреть за доступными личными данными и своевременно напоминать человеку о важном**.

Ручной ввод Capture / Захвата памяти остаётся полезной дополнительной функцией, но он не является главным смыслом продукта. Основной смысл — чтобы приложение само помогало владельцу помнить, готовиться и реагировать вовремя.

## Главный продуктовый принцип

```text
Приложение должно быть пассивным личным радаром.
Человек не должен жить внутри приложения.
Приложение должно жить рядом с человеком и вовремя подсказывать.
```

Это означает:

- приложение должно работать в фоне настолько, насколько это разрешает Android;
- оно должно читать разрешённые владельцем источники данных;
- оно должно превращать события, захваты, голосовые фразы и будущие источники в RadarCard;
- оно должно давать своевременные уведомления;
- оно не должно требовать постоянного ручного заполнения;
- ручной текстовый ввод — это запасной и дополнительный канал;
- голосовой ввод — быстрый канал захвата мысли;
- календарь — один из ключевых пассивных источников;
- будущие источники должны подключаться через тот же принцип: владелец разрешил → приложение анализирует → напоминает вовремя.

## Что такое Capture / Захват памяти

Capture — это сырой кусок жизни:

- мысль;
- обещание;
- идея;
- задача;
- фраза;
- рабочая информация;
- риск;
- план;
- событие;
- напоминание.

Capture может появляться вручную, голосом или из разрешённых источников вроде календаря.

## Базовый поток

```text
Source
→ Capture
→ Analysis
→ RadarCard
→ Notification / Action
→ Memory Update
→ Reflection
```

Где `Source` — это источник данных:

- ручной текстовый ввод;
- голосовой ввод;
- календарь телефона;
- в будущем: другие разрешённые владельцем источники.

## Текущий рабочий срез

Репозиторий содержит Android-проект `com.personalradar.app` и рабочее ядро:

- ввод Capture / Захвата памяти;
- сохранение Capture в локальную Room-базу;
- базовый rule-based анализ текста;
- создание RadarCard;
- отображение активных Radar-карточек на экране;
- объяснение причины появления карточки через `whyText`;
- debug APK через GitHub Actions artifact;
- начатая интеграция календаря телефона как пассивного источника.

## Текущий архитектурный путь

```text
MainActivity
→ AppContainer
→ CaptureRadarController
→ QuickCaptureRepository
→ Room DAO / Entity
```

Календарный источник развивается как отдельный вход в тот же поток:

```text
CalendarSourceReader
→ CalendarSourceEvent
→ Capture text
→ QuickCaptureRepository
→ RadarCard
```

## CI

GitHub Actions выполняет:

```bash
gradle -Pandroid.useAndroidX=true -Pandroid.nonTransitiveRClass=true assembleDebug --stacktrace
```

После сборки workflow выгружает debug APK как artifact:

```text
personal-ai-radar-debug-apk
```

## Проверки, которые уже проходили

- Gradle запускается в GitHub Actions.
- AndroidX включён через `gradle.properties`.
- Kotlin-код компилировался в предыдущих зелёных сборках.
- Room Entity/DAO проходили сборку.
- Первый вертикальный сценарий Capture → RadarCard собирался.
- APK устанавливался и запускался на Android-телефоне.

## Ближайшая цель разработки

Сейчас нельзя просто накидывать новые функции. Нужно стабилизировать passive-first прототип:

1. Починить текущий билд после календарных изменений.
2. Проверить APK на телефоне.
3. Проверить, что ручной Capture не сломан.
4. Проверить, что карточки сохраняются после перезапуска.
5. Проверить календарный импорт как пассивный источник.
6. Проверить своевременность уведомлений.
7. После этого улучшать анализ, нормализацию текста и качество напоминаний.

## Что приложение не должно превращаться

Приложение не должно становиться:

- обычным блокнотом;
- обычным todo-листом;
- приложением, где нужно постоянно сидеть;
- шумной напоминалкой;
- скрытой прослушкой;
- облачным сервисом, который бесполезен без интернета.

Главный ориентир: **человек живёт своей жизнью, а Радар тихо помогает ему не упустить важное**.
