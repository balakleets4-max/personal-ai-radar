# Observability: crashes and build health

Цель этого документа — подключить мониторинг так, чтобы он помогал ловить реальные ошибки, но не ломал принцип проекта: **AI Радар должен оставаться offline-first**.

## Что уже подключено в репозитории

- GitHub Actions собирает debug APK и запускает unit-тесты.
- Dependabot проверяет Gradle-зависимости и GitHub Actions.
- GitHub Issues используются как журнал задач, багов и подключений.

## Sentry

Sentry нужен для крашей и ошибок приложения.

### Что нужно сделать вручную

1. Создать аккаунт или войти в Sentry.
2. Создать проект Android/Kotlin.
3. Получить DSN.
4. Добавить DSN не в код напрямую, а через безопасную конфигурацию.

### Правило для проекта

Не включать агрессивный сбор данных. Для AI Радара допустимы:

- краш-репорты;
- технические ошибки;
- версия приложения;
- модель устройства;
- Android version.

Не отправлять:

- тексты Capture;
- содержимое RadarCard;
- календарные названия событий;
- голосовые данные;
- персональные заметки пользователя.

## Firebase Crashlytics

Crashlytics — альтернатива или дополнение к Sentry для Android-крашей.

### Что нужно сделать вручную

1. Создать Firebase project.
2. Добавить Android app с package name:

```text
com.personalradar.app
```

3. Скачать `google-services.json`.
4. Поместить файл в корень Android app-модуля.
5. Не коммитить реальные приватные ключи и лишнюю конфигурацию без проверки.

## Важное решение

Не подключать Sentry и Crashlytics одновременно вслепую в код, пока не выбран основной канал краш-аналитики.

Рекомендуемый порядок:

1. Сначала GitHub Actions + Issues + Dependabot.
2. Потом Sentry как лёгкий мониторинг ошибок.
3. Потом Crashlytics, если нужен именно Android-native crash pipeline.

## Definition of Done

Подключение observability считается готовым, когда:

- debug APK собирается в GitHub Actions;
- unit-тесты запускаются в CI;
- Dependabot создаёт PR по зависимостям;
- есть хотя бы один тестовый crash/error event в выбранном сервисе;
- проверено, что личные тексты пользователя не отправляются наружу.
